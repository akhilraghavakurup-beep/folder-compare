# Folder Compare & Duplicate Finder

A 100% private, client-side web application to compare two folders for duplicate files and filter unique files directly in your browser.

- **No installation needed**
- **No command line or PowerShell needed**
- **100% Offline & Private** (Zero network requests, files are read locally in browser RAM)
- **Features**: Exact SHA-256 content hashing, Quick mode, Duplicate filter, Non-duplicate filter, Search, and CSV export.
